# .github

Org-wide defaults for OQTS: the profile shown on github.com/oqts, issue and pull request templates, the repository-request form, and [CONTRIBUTING.md](CONTRIBUTING.md).

[CLAUDE.md](CLAUDE.md) is the org guidance for coding agents, including the repo map and where each kind of document lives. [docs/org-setup.md](docs/org-setup.md) is the historical record of how the GitHub org was set up.
